Our Approach — Two Contributions

Contribution 1
Physical Verification Correctness Contract
Six-layer fail-closed contract covering structural, geometric, temporal, electrical, and logical correctness.

Timing-Path-Guided Mutation
STA critical paths feed back into the mutation operator, biasing changes toward blocks that influence timing.

PVCC — Six Verification Layers

L1  Compilation + CTest Regression Structural CMake + 5 tests
L2  KLayout Physical DRC Geometric XML parse → 0 items
L3  Independent STA Audit Temporal frozen stock binary
L4  Timing Regression Gates Temporal no WNS/TNS regression
L5  Electrical / Physical Gates Electrical 7 metrics = 0
L6  Yosys Formal Equivalence Logical equiv_induct proven
Fail-closed — any layer fails → reject
Evidence-bearing — SHA-256 per layer
Auditable — full provenance chain

Champion Evolved Policy

Stock (baseline)
double score = 0.0; score += f.load; return score;
Only considers load capacitance.
Evolved (+4.88% WNS)
double score = 0.0; score += f.load; score += 0.35 * f.load * std::log1p(f.fanout); if (f.position > 0.65) { score += 0.20 * f.load; } score -= 0.05 * f.position * f.position; return score;
Adds fanout pressure, late-path boost, position damper.

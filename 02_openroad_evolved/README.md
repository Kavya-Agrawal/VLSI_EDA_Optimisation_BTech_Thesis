# 02_openroad_evolved — the evolving Resizer code

- `champion/rsz/`: current best full `src/rsz` tree (starts identical to the original).
- `champion.patch`: unified diff champion vs original.
- `candidates/<iter>_<id>/`: one folder per proposal: `rsz/` tree, `candidate.patch`, `HYPOTHESIS.md`, `verdict.json`.
- `lineage.json`: parent/child relations, accepted/rejected, scores.

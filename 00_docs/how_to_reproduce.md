# How to reproduce on a fresh machine

Works on macOS (Apple Silicon or Intel), Ubuntu/Debian, or inside the Docker image. Bazel downloads
its own compiler, Tcl and libraries, so the build recipe is identical everywhere.

## 1. Clone and install OS dependencies

```bash
git clone <this repo> && cd <repo> && git checkout pv_resizer_evolve
make deps            # macOS: brew install bazelisk yosys python@3.12 pipx rsync jq; pipx install graphifyy
                     # Linux: apt packages + bazelisk binary + pipx graphifyy
```

Claude Code CLI: `curl -fsSL https://claude.ai/install.sh | bash` (or set `CLAUDE_BIN=/path/to/claude`).
The agents call `claude -p` with your logged-in account; no API key file is needed.

## 2. Sources at the pinned commits

```bash
make setup           # external/OpenROAD @ VERSIONS.lock[openroad].commit, ORFS likewise, python venv
make env-check       # must end with "RESULT: ready"
```

## 3. Build stock OpenROAD and freeze the resizer

```bash
make build-openroad  # bazelisk build //:openroad ; 1-2 h cold, minutes warm. BAZEL_JOBS=4 on 8 GB machines
make snapshot        # 01_openroad_original/rsz_snapshot + champion initialised to the original
make lock-versions   # appends exact versions seen on this machine to VERSIONS.lock
```

## 4. Phase 1: knowledge graph and agent context

```bash
make graphify        # 08_graphify/full_openroad and 08_graphify/rsz_focus (code-only extraction is offline)
make context         # 09_agent_context/* via a headless Claude pass over the graph + sources
```

## 5. Benchmarks and baseline

```bash
make checkpoints TIER=A    # ORFS synth->floorplan->place->repair_design->detailed place; copies placed.odb + SDCs
make baseline TIER=A       # stock binary, 3 replicates per design per SDC variant -> 05_baseline_results/
```

## 6. Evolve

```bash
make evolve N=5 BUDGET_USD=20 TIER=A      # stops at N iterations or when spend passes BUDGET_USD
make evolve-resume N=5                    # continue
make validate-champion                    # Tier C on the champion
make report && make viz                   # tables and 07_visualizations/index.html
```

## Docker (Linux container, any host)

```bash
make docker-build
make docker-shell          # then inside: make setup build-openroad snapshot ...
```

The Bazel cache lives in the named volume `pv-rsz-bazel-cache`, so rebuilding the image does not
rebuild OpenROAD.

## Determinism notes

- `repair_timing` is deterministic for a given binary, checkpoint and SDC; replicates exist to catch
  non-determinism introduced by a candidate (threads, unordered containers). Baseline uses 3, the loop 2.
- Checkpoints are produced once and committed as `design.json` + SDCs; the `.odb` files are regenerated by
  `make checkpoints` (ORFS + Yosys are deterministic for pinned versions).

\begin{abstract}
\noindent
This manual is a \textbf{concise, complete engineering reference} to the OpenROAD
application codebase (the RTL-to-GDSII place-and-route engine). It is written to
be read once front-to-back, then used as a lookup reference. Every chapter maps
onto part of the \file{src/} tree --- naming the real modules, C++ classes,
key functions, and Tcl commands --- and explains how data flows through the
shared OpenDB database and OpenSTA timer rather than restating code
line-by-line. The embedded \pkg{src/abc} copy of Berkeley ABC is intentionally
\emph{not} covered here; it is documented separately in the ABC reference manual.
After this manual you can locate, read, and modify any stage of the flow.
\end{abstract}

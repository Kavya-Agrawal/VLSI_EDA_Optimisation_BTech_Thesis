# 09_agent_context — what the agents read

- `00_BIG_PICTURE.md`: what rsz solves, where it sits in the flow, the rsz<->STA loop, inputs/outputs.
- `files/<File>.md`: one card per rsz source file (purpose, entry points, precise I/O, callers/callees, invariants).
- `algorithms/<cluster>.md`: one dossier per algorithm cluster (problem, current heuristic, weaknesses, literature, owned files).
- `clusters.json`: machine-readable cluster -> files / entry points / tests / editable vs read-only.
- `GLOSSARY.md`, `EVAL_CONTRACT.md`.

Generated by `make context`; hand-edits are allowed and preserved (see decisions.md).

# 04_benchmarks — what the Resizer is evaluated on

- `designs/<pdk>/<design>/`: placed checkpoint (`placed.odb`), `nominal.sdc`, `stressed.sdc`, `setRC.tcl`, liberty paths, `design.json` (period, endpoints, provenance).
- `tiers.json`: Tier A (every iteration), B (escalation), C (final validation).
- `scripts/`: checkpoint generation via ORFS up to detailed placement.

Large binaries (`*.odb`) are git-ignored and regenerated by `make checkpoints`.

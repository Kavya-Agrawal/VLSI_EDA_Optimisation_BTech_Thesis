\begin{abstract}
\noindent
This manual is a \textbf{concise, complete engineering reference} to the Berkeley
ABC codebase. It is written to be read front-to-back once and then used as a
lookup reference. Every chapter maps directly onto a part of the \file{src/}
tree, names the real files, structs, functions, and constants involved, and
explains the data flow rather than restating line-by-line code. The goal: after
this manual you can locate, read, and modify any part of ABC without getting
lost in \(\sim\)2300 source files.
\end{abstract}
